# Companion assets

This directory contains source artwork and design references for the optional Wolfy companion feature.

## Packs

- `notionists-v1/raw`: immutable source archives and original design files uploaded by the project owner.
- `notionists-v1/library/vector`: extracted and consistently named SVG components.
- `notionists-v1/library/raster`: extracted and consistently named PNG components.
- `notionists-v1/library/examples`: complete example characters from the source pack.
- `notionists-v1/generated`: AI-generated concept sheets for new Wolfy-specific outfits, accessories, hair, and reading poses.
- `notionists-v1/manifests`: machine-readable inventory and integration metadata.

## Runtime rule

Nothing in `raw` or `generated` may be bundled into a release application. The generated PNG files are visual references, not production sprites. They contain a baked checkerboard background and have no alpha channel.

Production assets must first be redrawn or vectorized into a normalized `runtime` pack. Every runtime layer must use the same view box, anchors, stroke rules, color tokens, and clipping bounds. The implementation prompt in `docs/WOLFY_COMPANIONS_IMPLEMENTATION_PROMPT.md` defines that pipeline.


## Runtime pack

`notionists-v1/runtime` is generated by `tools/companions/normalize.mjs` from the vector library and validated by `tools/companions/validate.mjs` (CI step). Only confirmed layers ship: every layer position is proven against the 18 source example characters. Runtime SVGs share a 1024x1024 canvas, use color tokens (`--wolfy-skin`, `--wolfy-hair`, `--wolfy-outfit`, `--wolfy-accent`, `--wolfy-ink`) and never contain scripts, rasters or external references. Do not edit runtime files by hand.
